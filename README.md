# 极地救援站 · 呼救电文复原

受潮无线电纸带的摩尔斯电文复原工具。值班员在浏览器录入**按出现顺序的明暗游程**与**允许的单单位时长范围**，
应用在整个序列上**共同选择一个整数单位时长和各游程解释**（信号游程→点/划，空白游程→符内/符间/词间停顿），
使解释后的摩尔斯序列恰好译成受限字母表与词典中的词，避免把局部最接近的点划误拼成不存在的呼号。

## 复原规则

- 纸带必须以信号游程开始并结束（游程段数为奇数），信号/空白交替。
- 时序模型（单位 u）：点 = 1u，划 = 3u，符内停顿 = 1u，符间停顿 = 3u，词间停顿 = 7u；u 为范围内整数。
- 多个可行复原的择优顺序：
  1. **总绝对时长偏差**最小（Σ|录入时长 − 解释理想时长|）；
  2. **单段最大偏差**最小；
  3. 按游程顺序的**解释编码**（点`.` 划`-` 符内`:` 符间`|` 词间`#`）字典序稳定取舍，仍并列时单位时长小者优先。
- 无解时按**最早无法落入任何有效词典前缀的游程**显示原因与未能译码的位置，绝不给出貌似完整的电文。
- 草稿任一改动立即使旧电文失效（界面标记"已失效"，需重新复原）。

## 本地开发

```sh
npm install
npm run dev        # 开发服务器
npm run test       # 单元测试（vitest）
npm run build      # 类型检查 + 生产构建
npm run smoke      # 复原核心样例冒烟（编译 dist-core 后运行）
```

## Docker 运行

```sh
# 构建并启动静态站点（默认映射 8080，可用 WEB_PORT 覆盖）
WEB_PORT=8080 docker compose up --build web

# 健康检查
curl http://localhost:8080/healthz   # → ok
```

Compose 中 `web` 服务自带 HTTP 健康检查（`wget http://127.0.0.1/healthz`）。

## 一次性验证服务 verify

```sh
docker compose up --build --exit-code-from verify verify
echo $?   # 0 = 全部通过
```

`verify` 依次执行并在**退出码**中报告结论（位掩码，可组合）：

| 位 | 含义 |
|----|------|
| 1  | 单元测试失败 |
| 2  | 生产构建失败 |
| 4  | 健康端点冒烟失败 |
| 8  | 复原核心样例冒烟失败 |

## 目录结构

```
src/core/       复原核心（纯 TS，无 UI 依赖）：电码表、纸带生成、联合解码器
src/            React 前端（游程编辑、逐段解释/累计偏差/词界/失败位置展示）
tests/          vitest 单元测试
scripts/        verify.sh（一次性验证）、smoke.mjs（核心样例冒烟）
deploy/         nginx 配置（含 /healthz）
```
